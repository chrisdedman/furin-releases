# Fūrin 風鈴

A cozy RPG for the Mac about the spirits of the summer wind, set in Kazamachi, a seaside town in Japan. You can also pick up some Japanese along the way, or switch that off in Settings and just play.

This repo only holds the finished game. Once it's installed, Fūrin updates itself: when a new version is out, it offers to install it and relaunch, and your save is kept.

## Install

Needs macOS 14 Sonoma or later, on an Apple Silicon or Intel Mac.

1. Download **Furin-….zip** from the [latest release](https://github.com/chrisdedman/furin-releases/releases/latest) and open it to unzip.
2. Drag **Furin** into your **Applications** folder. Keep it there: updates install in place.
3. Open it. Fūrin isn't from the App Store, so the first time macOS says it can't check it. Click **Done**, not Move to Trash.
4. Open **System Settings › Privacy & Security**, scroll down to the message about Furin, click **Open Anyway** and confirm.

That's needed only once. After that it opens like any other app.

On macOS 14 you can instead Control-click Furin in Applications, choose **Open**, then **Open** again.

## Updates

Fūrin checks for updates when it starts and about once an hour while you play. You can also choose **Fūrin › Check for Updates…** in the menu bar.
